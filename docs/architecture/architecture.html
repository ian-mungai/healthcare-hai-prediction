healthcare-hai-prediction Architecture

Acquisition stage: public health data collected through APIs and download URLs into private S3 storage; modeling platform planned

Acquisition

  • • Publisher APIs first, then download URLs; manual export only by choice
  • • Locked plans and reviewed code versions gate every new capture
  • • Raw responses kept byte for byte; CSVs derived and replayed offline
  • • Holds on definitions, geography and modeling stay in place

Storage and access

  • • One versioned, encrypted, TLS-only bucket with public access blocked
  • • Confidential: redacted derivatives and releases naming individuals
  • • Originals with personal data stay local with owner-only access
  • • Deferred: access logging, KMS, replication, event notifications

Verification

  • • Local CI and GitHub Actions run the same script
  • • E2E runs leave repeatable artifacts under data/e2e
  • • Terraform plans are tested with a mock provider
  • • Infrastructure changes apply only from reviewed saved plans
